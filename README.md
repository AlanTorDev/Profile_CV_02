# Tam Minh Hoang CV — Theme Switchs

Open `index.html` directly in a browser.

Features:
- Dark mode is the default.
- Light/Dark switch in the navbar.
- Selected theme is saved to localStorage.
- 3D terminal and cards.
- Scroll reveal.
- Responsive layout.

To reset to Dark:
`localStorage.removeItem("cv-theme"); location.reload();`

V4 polish: precision-aligned experience timeline, responsive timeline geometry, animated timeline scan, stronger hover/glow interactions, and viewport-triggered stat count animation.
